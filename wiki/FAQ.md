# سؤال‌های متداول

## آیا روی گوشی مهمان VPN لازم است؟

خیر؛ در مسیر پشتیبانی‌شده، مهمان فقط به وای‌فای یا Ethernet خروجی متصل می‌شود. تنظیم پروکسی هم لازم نیست.

## برنامه خودش VPN ایجاد می‌کند؟

خیر. VPN باید از قبل روی کامپیوتر متصل باشد. برنامه اشتراک آن اتصال را مدیریت می‌کند.

## فایل Windows واقعاً پرتابل است؟

خود برنامه یک EXE مستقل است و نصب .NET نمی‌خواهد؛ اما درایور شبکه مؤلفه سیستمی جداگانه است و نصب آن به Administrator نیاز دارد. پرتابل‌بودن EXE به معنی اجرای بدون دسترسی شبکه یا بدون درایور نیست.

## آیا از ICS یا WinNAT استفاده می‌کند؟

مسیر فعلی Windows از NAT اختصاصی و Windows Packet Filter استفاده می‌کند و موتور اشتراک آن ICS یا WinNAT نیست. برای ساخت AP همچنان از APIهای سیستم‌عامل و قابلیت کارت شبکه استفاده می‌شود. Linux از NetworkManager و nftables بهره می‌برد.

## آیا با یک کارت وای‌فای می‌شود هم اینترنت گرفت هم هات‌اسپات ساخت؟

به درایور و پشتیبانی هم‌زمانی کارت بستگی دارد و تضمین نشده است. یک کارت آزاد و سازگار با AP، مسیر روشن‌تری برای خروجی جداگانه فراهم می‌کند. داشتن دو یا سه کارت نیز بدون پشتیبانی AP کافی نیست.

## چرا زدن × اشتراک را قطع نمی‌کند؟

در Windows، هنگام اشتراک فعال، بستن پنجره برنامه را به System Tray می‌برد. برای توقف، **Stop sharing** و برای خروج کامل، **Quit** از منوی آیکن کنار ساعت را استفاده کنید.

## Copy Wi-Fi چه چیزی کپی می‌کند؟

نام شبکه و رمز وای‌فای را در clipboard می‌گذارد. آن را در چت یا Issue عمومی paste نکنید.

## آیا kill switch و عدم نشت کاملاً تست شده‌اند؟

محافظت مسیر و توقف عبور مستقیم در طراحی وجود دارد، اما تست کامل نشت DNS/IPv6، قطع/وصل و crash روی مهمان هنوز تأیید نشده است. [وضعیت تست‌ها](Security-and-Testing.md)

## نسخه Linux آماده استفاده روزمره است؟

بسته و تست‌های منطقی آماده‌اند؛ هات‌اسپات واقعی Linux هنوز تأیید نشده است. این نسخه پیش‌نمایش است.

## استفاده تجاری از درایور آزاد است؟

درایور مجوز مستقل سازنده را دارد. شرایط تجاری و بازتوزیع را از [صفحه مجوز Windows Packet Filter](https://www.ntkernel.com/windows-packet-filter/licensing/) بررسی کنید؛ مجوز سورس برنامه جای آن را نمی‌گیرد.
