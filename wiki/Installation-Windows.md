# نصب و اجرای Windows

## پیش‌نیازها

- Windows 10 نسخه 2004، Build 19041 یا جدیدتر، یا Windows 11؛ معماری x64.
- حسابی با امکان تأیید Administrator برای تنظیمات شبکه و درایور.
- VPN متصل و اینترنت قابل استفاده روی خود کامپیوتر.
- کارت خروجی آزاد؛ برای Wi-Fi، پشتیبانی سخت‌افزار و درایور از AP لازم است.

## دریافت و بررسی فایل

از [صفحه Release](https://github.com/navidhaghpanah/vpn-share/releases/tag/v0.5.0-preview.2)، فایل `VPNShare-0.5.0-preview.2.exe` و `SHA256SUMS.txt` را بگیرید. در همان پوشه می‌توانید هش را محاسبه و با فایل منتشرشده مقایسه کنید:

```powershell
Get-FileHash .\VPNShare-0.5.0-preview.2.exe -Algorithm SHA256
```

برنامه به نصب جداگانه .NET نیاز ندارد. درایور جداگانه است: اگر Windows Packet Filter موجود نباشد، برنامه نصب‌کننده رسمی را دانلود می‌کند، هش و امضای آن را می‌سنجد و نصب را مدیریت می‌کند. در صورت خطای اعتبارسنجی، نصب را با خاموش‌کردن آنتی‌ویروس یا بررسی امضا دور نزنید؛ متن خطا را ثبت کنید.

## اولین اشتراک

1. اتصال اینترنت ورودی را برقرار کنید؛ می‌تواند Wi-Fi، LAN یا USB tethering باشد.
2. VPN را وصل و اینترنت خود کامپیوتر را بررسی کنید.
3. EXE را اجرا و UAC را تأیید کنید.
4. VPN درست را در فهرست بالای ویجت انتخاب کنید.
5. **Wi-Fi hotspot** را انتخاب کنید. نام شبکه باید ۱ تا ۳۲ بایت UTF-8 باشد؛ برای سازگاری بهتر از نام کوتاه انگلیسی استفاده کنید. رمز باید ۸ تا ۶۳ نویسه چاپ‌شدنی انگلیسی باشد.
6. در **Options**، حالت Automatic را نگه دارید یا کارت خروجی سازگار را انتخاب و تنظیمات را ذخیره کنید.
7. **Start sharing** را بزنید و منتظر وضعیت فعال بمانید.
8. روی گوشی یا دستگاه مهمان، به نام وای‌فای تنظیم‌شده وصل شوید. دریافت IP و بازشدن یک سایت تازه را بررسی کنید؛ برای تست گوشی، دیتای موبایل را خاموش کنید.

برای اشتراک کابلی، به‌جای مرحله ۵، **Ethernet** و کارت خروجی آزاد متصل به دستگاه مهمان را انتخاب کنید. مسیر Ethernet هنوز تأیید سخت‌افزاری این پیش‌نمایش را ندارد.

## توقف و بستن

**Stop sharing** را بزنید و اجازه دهید بازیابی تمام شود. هنگام اشتراک فعال، دکمه بستن پنجره برنامه را به System Tray می‌برد؛ برای خروج کامل، منوی آیکن کنار ساعت و **Quit** را استفاده کنید. **Hide** نیز فقط ویجت را پنهان می‌کند.

اگر **Restore network** دیده شد، اول بازیابی را اجرا کنید. فایل journal و قواعد محافظتی را دستی حذف نکنید. [راهنمای بازیابی](Troubleshooting.md)
