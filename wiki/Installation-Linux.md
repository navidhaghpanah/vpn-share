# نصب در Ubuntu / Debian

نسخه Linux یک رابط GTK با helper دارای دسترسی شبکه است. از NetworkManager، nftables، iproute2، DHCP/DNS و polkit استفاده می‌کند. داشتن محیط دسکتاپ و کارت سازگار با AP برای هات‌اسپات لازم است.

**وضعیت فعلی:** بسته DEB ساخته شده و ۳۶ تست منطقی و چرخه عمر موفق بوده‌اند. نصب و هات‌اسپات روی سخت‌افزار واقعی Linux هنوز تأیید نشده است.

## نصب

فایل `vpnshare_0.5.0.preview2_all.deb` را از [Release](https://github.com/navidhaghpanah/vpn-share/releases/tag/v0.5.0-preview.2) دانلود کنید و در پوشه آن اجرا کنید:

```bash
sha256sum vpnshare_0.5.0.preview2_all.deb
sudo apt install ./vpnshare_0.5.0.preview2_all.deb
```

خروجی دستور اول را با `SHA256SUMS.txt` همان Release مقایسه کنید. دستور نصب وابستگی‌ها را از مدیر بسته توزیع دریافت می‌کند.

## اجرا و استفاده

1. اینترنت و VPN را روی سیستم وصل کنید.
2. VPN Share را از منوی برنامه‌ها باز کنید، یا دستور زیر را اجرا کنید:

```bash
vpnshare
```

3. رابط را با کاربر عادی اجرا کنید؛ هنگام درخواست عملیات شبکه، تأیید polkit را انجام دهید.
4. VPN و خروجی موردنظر را انتخاب کنید؛ برای Wi-Fi نام شبکه و رمز را تعیین کنید.
5. اشتراک را شروع و با یک دستگاه مستقل، دریافت IP و دسترسی اینترنت را بررسی کنید.
6. برای پایان، اشتراک را از خود برنامه متوقف کنید و منتظر پایان بازیابی بمانید.

## اگر شبکه ساخته نمی‌شود

وجود NetworkManager فعال، امکان تأیید polkit و قابلیت AP کارت را بررسی کنید. محیط headless یا سیستمی که شبکه آن با ابزار دیگری مدیریت می‌شود، در این راهنما تأیید نشده است. بدون بررسی علت، قواعد nftables یا فایل‌های حالت برنامه را پاک نکنید.

## حذف بسته

ابتدا اشتراک را متوقف و برنامه را ببندید؛ سپس:

```bash
sudo apt remove vpnshare
```
