# رفع مشکل و بازیابی شبکه

## قبل از گزارش خطا

نسخه برنامه، مرحله وقوع خطا و متن **Options → Activity** را ثبت کنید. ابتدا مطمئن شوید اینترنت و VPN روی خود کامپیوتر کار می‌کنند. تغییر هم‌زمان چند تنظیم، تشخیص علت را دشوار می‌کند.

| نشانه | بررسی پیشنهادی |
| --- | --- |
| VPN پیدا نمی‌شود | اتصال VPN، فهرست کارت‌ها و انتخاب درست تونل را بررسی و دستگاه‌ها را دوباره اسکن کنید. |
| Start sharing خطا می‌دهد | متن کامل خطا در Options، نصب درایور و قابلیت AP کارت خروجی را بررسی کنید. |
| نام Wi-Fi دیده می‌شود ولی مهمان وصل نمی‌شود | رمز، پروفایل ذخیره‌شده مهمان و پشتیبانی AP را بررسی کنید؛ در صورت تغییر رمز، شبکه ذخیره‌شده قدیمی را در مهمان Forget کنید. |
| مهمان IP نمی‌گیرد | فعال‌بودن جلسه اشتراک و DHCP، کارت خروجی صحیح و متن Activity را بررسی کنید. |
| مهمان وصل است ولی اینترنت ندارد | اینترنت خود میزبان، VPN انتخاب‌شده، مسیرهای تونل و DNS را بررسی کنید؛ دیتای موبایل مهمان را برای تست خاموش کنید. |
| VPN interrupted | اتصال VPN میزبان را بررسی کنید. برنامه برای توقف عبور مستقیم طراحی شده، ولی تست کامل قطع/وصل و نشت هنوز تأیید نشده است. |
| Recovery pending یا Restore network | طبق بخش بازیابی زیر عمل کنید. |

## Restore network چه می‌کند؟

برنامه تغییرات جلسه را در journal نگه می‌دارد تا تنظیمات شبکه و هات‌اسپات را بازیابی کند. اگر بازیابی کامل نشود، نگه‌داشتن journal و قواعد محافظتی عمدی است؛ حذف دستی آن‌ها ممکن است وضعیت شبکه را نامشخص کند.

1. متن خطا را از Options بردارید.
2. **Restore network** را بزنید و منتظر پایان عملیات بمانید.
3. اگر خطا ادامه داشت، از شروع پیاپی جلسه‌های تازه خودداری کنید و گزارش خطا ارسال کنید.
4. برای بررسی، نسخه برنامه، نوع VPN، روش ورودی اینترنت و نوع خروجی را همراه متن پاک‌سازی‌شده خطا بنویسید.

در Preview 2، بازیابی AP باقی‌مانده در Windows فقط پس از تطبیق شناسه کارت، نام شبکه و مالکیت جلسه می‌تواند توقف اجباری همان AP را درخواست کند. تست‌های رگرسیون این شروط موفق‌اند؛ نتیجه واقعی بازیابی روی سخت‌افزار هنوز تأیید نشده است.

## خطای Wi-Fi AP: read AP settings با کد 1610

این خطا در یک نسخه قدیمی در اولین استفاده از تنظیمات AP مشاهده شد. فراخوانی آماده‌سازی تنظیمات WLAN به نسخه‌های بعدی اضافه شده است. ابتدا از Preview 2 استفاده کنید؛ اگر همان خطا ماند، متن Activity را گزارش کنید. تنظیمات شبکه را با اسکریپت‌های ناشناس یا با حذف دستی محافظت‌ها بازنشانی نکنید.

## چه اطلاعاتی عمومی نکنیم؟

رمز وای‌فای، مشخصات ورود VPN، کلیدها، نام‌های خصوصی کارت‌ها، IPهای حساس و شناسه‌های سخت‌افزاری را پیش از ارسال در Issue حذف کنید. لازم نیست فایل‌های کامل runtime یا journal را عمومی کنید.
